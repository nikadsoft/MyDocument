# MyDocument

A desktop Markdown editor built with **JavaFX 21**. Switch between Source, Preview, and WYSIWYG modes with a single click.

## Highlights

- CommonMark rendering with GFM extensions (tables, strikethrough, autolinks)
- Native installers for Linux, Windows, and macOS
- Open-source under the GNU GPL v3

## Downloads

Pre-built installers are attached to every [GitHub Release](https://github.com/nikadsoft/MyDocument/releases).

| Platform | Format |
|----------|--------|
| Linux    | `.deb` |
| Windows  | `.msi` |
| macOS    | `.dmg` |

## Quick start

```bash
git clone https://github.com/nikadsoft/MyDocument.git
cd MyDocument
./gradlew run
```
